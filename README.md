# 方林工作台下载

此仓库仅用于发布方林工作台公开安装包，不包含私有源代码、密钥或用户数据。

## Mac Apple 芯片测试版 V2.0.19

[下载及更新说明](https://github.com/fangming529/fanglin-workbench-downloads/releases/tag/workbench-2.0.19-test)

包含三维场景渲染、PPT 预览删除与图片压缩，以及 Mac 下载更新能力。TT-6Astra 暂未启用。此包尚未签名或公证，使用独立测试版渠道；不支持 Intel Mac。

已有 Mac 自动更新能力的测试版（2.0.18 起）可在工作台设置中更新。2.0.17 及更早版本需手动安装一次本版，保留原有数据目录。

工作台自动检查的 Mac Apple 芯片测试渠道清单位于 `updates/mac-test-arm64.json`。Windows 和正式版渠道不随本次发布切换。
